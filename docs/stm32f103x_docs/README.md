# Tai lieu tham khao STM32F103

Tai lieu goc duoc tai tu thu muc nay la tai lieu co ban quyen cua STMicroelectronics va Arm. De tranh phan phoi ban sao trong repository, cac PDF goc duoc giu local va khong dua vao commit. Tai lieu chinh thuc co the tai tu cac trang sau:

- [STM32F103C8 product page - datasheet va tai lieu ST](https://www.st.com/en/microcontrollers-microprocessors/stm32f103c8.html)
- [STM32F1 reference manual RM0008](https://www.st.com/resource/en/reference_manual/cd00171190-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)
- [STM32F10xxx Flash programming manual PM0075](https://www.st.com/resource/en/programming_manual/cd00283419-stm32f10xxx-flash-programming-manual-stmicroelectronics.pdf)
- [Arm Cortex-M3 Technical Reference Manual](https://developer.arm.com/documentation/ddi0337/latest)

Kiem tra dieu khoan su dung tai trang cua nha san xuat truoc khi tai hoac phan phoi tai lieu.
